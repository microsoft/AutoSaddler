# Meta-ARE Reflection Contract (Plugin-specific)

Read `.autosaddler/session_context.json` for the Meta-ARE parent, child,
selection, changed paths, patch phase, diagnosis, matched training scores,
acceptance reason, and aggregate development scores when available.

Return lessons using the supplied Meta-ARE reflection schema. Useful scopes
include GAIA2 agent behavior, capability design, default-agent prompts, tool
descriptions and implementations, configuration, hooks, and mutation safety.
`evidence_case_ids` may contain only training case IDs supplied in the current
context.
